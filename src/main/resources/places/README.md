# places/cities.tsv

Trimmed extract of the GeoNames `cities15000` dump (all cities with a population
above 15,000) — https://www.geonames.org/ — licensed **CC BY 4.0**.

Columns (tab-separated): name, ascii name, alternative names (`|`-separated,
Latin and Arabic script only, max 10), latitude, longitude, ISO country code,
population, IANA time zone.

Any API response built from this data names GeoNames as the source.
